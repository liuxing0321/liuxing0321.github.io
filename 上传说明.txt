【先查看效果】
双击 index.html，浏览器即可直接打开。头像和样式均已嵌入，无需安装软件。

【上传到新仓库】
1. 登录 GitHub，新建公开仓库（Public）。
   推荐仓库名：liuxing0321.github.io（此名称已存在时，需先处理旧库或另取名，例如 liuxing-homepage）。
2. 仓库中选择 Add file → Upload files。
3. 将本包中的 index.html 和 .nojekyll 两个文件上传至仓库根目录，点击 Commit changes。
   不要仅上传 ZIP，也不要把外层 github-ready 文件夹整个套进去。
4. 进入 Settings → Pages，Source 选择 Deploy from a branch。
5. Branch 选择实际存放文件的分支（新仓库通常是 main），目录选 /(root)，点击 Save。
6. 到 Actions 查看本次 pages build and deployment，成功后在 Pages 页面点击 Visit site。

【为什么这次不需要 Jekyll】
这是直接可打开的 HTML 文件，不包含 Liquid 模板、Ruby 或外部样式依赖。.nojekyll 用于跳过 Jekyll。新仓库不要上传旧模板的 Gemfile、_config.yml、_layouts 等文件。
